# 🏋️‍♂️ IFITNESS

Página web moderna em **Django**, rápida e focada em conversão, criada para substituir o atendimento manual do Instagram por uma plataforma completa.

## ✨ Features & Seções

* **Landing Page de Conversão:** Estrutura e diferenciais (equipamentos, climatização, avaliação), prova social com depoimentos reais e mapa integrado.
* **Grade de Aulas Filtrável:** Filtro dinâmico por modalidade (*Spinning*, *FitDance*, *Cross* e *Muay Thai*).
* **Portal do Aluno (UI):** Templates Django modulares preparados para autenticação, dados reais e visualização interativa de divisão de treino e séries.
* **Calculadora IMC & TMB:** Cálculo instantâneo no *client-side* para retenção de visitantes.

## 🛠️ Stack

* **Back-end:** Python, Django
* **Front-end:** Django Templates, HTML5, CSS3, JavaScript
